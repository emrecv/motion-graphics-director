# Art direction for a moving image

Read when the visual direction is open, a reference is supplied, or a clip looks generic despite working technically.

## Current creative profile

Follow the creative defaults in SKILL.md. Prioritize the first-three-second hook, one central visual, generous negative space, muted colors, borderless composition and modest radii. Let voice explain; remove explanatory paragraphs, oversized headings and editorial/interface chrome. A dark grid may be subtle context when requested. Do not inherit the legacy CDN look.

## Convert adjectives into design choices

"Clean", "premium", and "dynamic" are not sufficient specifications. State concrete choices: typeface and weights, scale contrast, alignment, palette, spacing, image treatment, motion character, and sound character. Use a small set of related decisions rather than an effect catalogue.

For a supplied reference, record what is actually observable: composition, density, type hierarchy, texture, cuts, movement paths, timing, and relationship to audio. Separate observation from interpretation. Describe the transferable principles; do not pretend to have watched a video that tools could not play.

Two directions should differ structurally. For example, one may use restrained typography, negative space, and precise masked reveals; another can use oversized type, saturated fields, and playful transformations. A palette swap is not a second direction.

## Styleframe review

Use meaningful moments: the opening message and a representative middle or closing scene. Use the intended words, not lorem ipsum. Show the frames at the real aspect ratio and approximate phone viewing size.

Check:

- Can a first-time viewer tell where to look immediately?
- Are related items aligned and grouped? Are margins deliberate?
- Does the type hierarchy remain clear without animation or sound?
- Do line breaks support the phrase? Avoid an isolated weak word or unwanted break in a brand name.
- Are secondary labels genuinely useful? Remove decorative interface chrome that implies nonexistent features.
- Is text placed away from the expected platform interface? Use a visible safe-area guide in the working project and adjust it for the actual placement, not a supposedly universal social safe area.

Typography needs optical judgment. A mathematically centered word can look off-center; a nominal font size does not ensure matching visual size across faces. Load the actual fonts before judging or measuring.

## Scene planning

Assign one main communicative action per scene. Supporting motion can reinforce it, but simultaneous actions should not compete. Use a few consistent visual motifs to connect scenes.

Write the shot list as a compact table with time range, message, primary image, movement, and sound. Keep the total duration consistent with the brief. Start with the strongest useful idea; a logo reveal is not automatically the best opening.

Plan transitions as relationships: an object carries into the next scene, a shape becomes a frame, a word introduces its explanation, or a hard cut changes the thought. Add an effect only when it serves that relationship.

## Common quality failures

- Gradients, glow, glass panels, film grain, or blur used to conceal weak composition.
- Every title using the same word stagger, regardless of sentence structure.
- Large margins on desktop that become cramped after a naïve portrait conversion.
- Detailed imagery or a dense caption competing with the headline.
- Continuous movement that leaves no time to read or appreciate the result.
- A good first frame followed by scenes whose composition was never designed.

Use the fewest elements needed for the idea, but do not confuse minimalism with empty or underdeveloped work.
